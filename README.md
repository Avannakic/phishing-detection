# Генерация и фильтрация LLM-синтетики для детекции русскоязычного фишинга

Официальный репозиторий пайплайна генерации синтетических данных, подготовки выборок и дообучения трансформера (`DeepPavlov/rubert-base-cased`) со стратифицированной 5-фолдовой кросс-валидацией для обнаружения фишинговых атак в мессенджерах.

---

## 1. Постановка задачи и схема разметки классов

Данные размечены на **3 непересекающихся класса** для разделения бытового общения, коммерческого спама и целевых социоинженерных атак:
- **`0` (Legitimate / Ham):** Легитимные пользовательские сообщения и информационные сводки.
- **`1` (Spam):** Массовая коммерческая рассылка, навязчивая реклама товаров/услуг и серые офферы без прямой попытки кражи учетных данных или средств получателя.
- **`2` (Phishing):** Целевые фишинговые атаки социальной инженерии (выманивание кодов авторизации, учетных данных, переводы на «безопасные счета», переход на фишинговые ресурсы и вредоносные боты).

Реальный корпус фишинга ($N = 300$, `New_Ready_phishing(300).csv` / `real_phishing.csv`) собран методом OSINT из верифицированных сводок по кибербезопасности: из публикаций извлекались исключительно прямые цитаты реальных мошеннических сообщений без сопутствующего журналистского контекста.

---

## 2. Метод генерации и параметрический промптинг

Генерация синтетических фишинговых сообщений выполнялась в режиме **zero-shot** (без подачи реальных примеров из тестового набора в промпт, что исключает прямое копирование) с помощью локальной языковой модели **`llama3` (Meta Llama 3 8B Instruct, квантование `Q4_0`)** через фреймворк **Ollama** при температуре **`temperature = 0.8`**.

Для обеспечения высокого лексического и структурного разнообразия вместо статического промпта использовалась **комбинаторная матрица параметрических промптов** в две итерации:
1. **Базовая генерация (`01_generate_base_phishing.py`):** 10 типовых ролей отправителей (Госуслуги, ЦБ РФ/ФСБ, ректорат/деканат, крупные банки, родственники/знакомые, поликлиника, официальная поддержка Telegram, боты с бесплатным Telegram Premium, боты знакомств/18+, магазины ключей Steam/нейросетей) × 2–3 психологические тактики манипуляции (давление авторитетом, страх блокировки/уголовной ответственности, жадность, срочность).
2. **Целевая догенерация сложных случаев (`02_generate_targeted_addition.py`):** Фокусное расширение 6 сценариев, мимикрирующих под рекламный спам (банковский кешбэк, голосования в конкурсах, крипто-чеки с раздачей средств, токены для ChatGPT, сливы 18+).

### Генерация фоновых классов для чисто синтетической модели (`00_generate_ham_and_spam.py`)
Для обучения «Модели 2» (`4_Model2_PureSynthetic`) без участия реальных данных с помощью той же модели `llama3` (`temperature = 0.8`) были сгенерированы фоновые корпуса:
- **Синтетический Ham (`label = 0`, 14 000 сообщений):** бытовые диалоги в мессенджерах, рабочая переписка, обсуждение новостей и короткие повседневные реплики без коммерческих предложений и подозрительных ссылок.
- **Синтетический Spam (`label = 1`, 14 000 сообщений):** массовые рекламные рассылки (маркетплейсы, скидки, промокоды, инфобизнес, вакансии удаленной работы, реклама Telegram-каналов) без социоинженерного выманивания паролей, кодов авторизации или переводов средств.

### Управляемые параметры внутри шаблона промпта:
- **Градация длины текста (`ALLOWED_LENGTHS`):** 
  * *Короткие:* 1–2 предложения (до 150 символов) — пакетная генерация по 10 шт.
  * *Средние:* 3–5 предложений (до 300 символов) — по 4 шт.
  * *Длинные:* развернутый текст (500–700 символов) — по 2 шт.
- **Вероятностный контроль эмодзи (`EMOJI_RULES`):** Индивидуальная вероятность использования эмодзи в зависимости от профиля отправителя — от `1–2%` («Пиши СТРОГО БЕЗ эмодзи, сухой канцелярский язык») для имитации Госуслуг и силовых ведомств до `80–90%` обильных кликбейтных эмодзи для мошеннических ботов.
- **Баланс наличия ссылок:** 50% вероятности органичной вставки URL-адреса против 50% текстового призыва к действию без ссылки.

## 3. Очистка, процедурная обработка и сборка датасетов

Весь цикл от генерации до формирования выборок и кросс-валидации автоматизирован:

- **Шаг 3: Очистка и фильтрация (`03_clean_and_filter.py`)** 
  Удаление строк с артефактами LLM («я не могу», «as an AI», «вот сгенерированные сообщения»), фильтрация по длине, количеству кириллических символов и очистка от Markdown-разметки.
- **Шаг 4: Слияние пулов (`04_merge_synthetic_pools.py`)**
  Дедупликация и объединение базовых и целевых генераций в единый датафрейм.
- **Шаг 5: Процедурная генерация URL (`05_procedural_urls.py`)**
  Замена плейсхолдеров (вида `example.com` или `[ссылка]`) на случайно сгенерированные правдоподобные URL-адреса и домены с использованием регулярных выражений.
- **Шаг 6: Сборка выборок и Data Leakage Prevention (`06_build_training_datasets.py`)**
  Двухэтапная фильтрация точных и нечетких пересечений между синтетическими и реальными тестовыми данными с помощью `TF-IDF` на униграммах и биграммах (удаляются любые синтетические примеры с косинусным сходством $\ge 0.85$).

## 4. Дообучение RuBERT и стратифицированная 5-фолдовая кросс-валидация (`07_train_rubert_cv.py`)

Для обеспечения статистической значимости результатов и исключения утечек данных между выборками реализован единый скрипт кросс-валидации на 5 фолдах (`StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`).

### Схема разбиения данных в каждом фолде:
- **Фоновые классы (Ham и Spam):** 14 000 реальных Ham и 14 000 реальных Spam в `Train` (после строгой очистки от любых пересечений с `Val` и `Test`), по 3 000 примеров в `Val` (`real_ham_val_3k.csv`, `real_spam_val_3k.csv`) и по 3 000 примеров в изолированном `Test` (`real_ham_test_3k.csv`, `real_spam_test_3k.csv`).
- **Целевой класс (Phishing, 300 реальных примеров):** На каждом из 5 фолдов 60 примеров (20%) откладываются в слепой `Test`, а оставшиеся 240 примеров делятся на `Train` (200 примеров) и `Val` (40 примеров для выбора лучшей эпохи по метрике `f1_macro`).

### Исследуемые конфигурации моделей (9 экспериментов):
1. **`1_Baseline_Imbalanced`:** Базовая модель на реальных данных с естественным дисбалансом (14 000 Ham, 14 000 Spam, 200 Real Phishing — дисбаланс 1:70).
2. **`2_Baseline_ClassWeights`:** Обучение на тех же несбалансированных данных со взвешенной функцией потерь `CrossEntropyLoss` (вес класса фишинга обратно пропорционален его доле).
3. **`3_Baseline_Oversampling`:** Классический Random Oversampling (дублирование 200 реальных обучающих примеров фишинга до 7 000).
4. **`4_Model2_PureSynthetic`:** Чисто синтетическая модель (14 000 Synth Ham, 14 000 Synth Spam, 7 000 Synth Phishing).
5. **`5_Model3A_Hybrid_PureSynthPhish`:** Гибрид без реального фишинга в обучении (14 000 Real Ham, 14 000 Real Spam, 7 000 Synth Phishing).
6. **`6_Model3_Hybrid_Full_100pct` (34x):** Полный гибрид (200 Real Phishing + 6 800 Synth Phishing = 7 000).
7. **`7_Ablation_Hybrid_50pct` (17x):** Дозированная аугментация 50% от целевого объема (200 Real Phishing + 3 400 Synth Phishing = 3 600).
8. **`8_Ablation_Hybrid_25pct` (8.5x):** Дозированная аугментация 25% (200 Real Phishing + 1 700 Synth Phishing = 1 900).
9. **`9_Ablation_Hybrid_10pct` (3.4x):** Дозированная аугментация 10% (200 Real Phishing + 680 Synth Phishing = 880).

### Гиперпараметры обучения и выходные файлы:
- **Модель:** `DeepPavlov/rubert-base-cased` (`max_length = 256`).
- **Параметры `TrainingArguments`:** 3 эпохи, `per_device_train_batch_size = 64`, `per_device_eval_batch_size = 128`, `warmup_steps = 150`, `weight_decay = 0.01`, смешанная точность `fp16`, сохранение лучшего чекпоинта на валидации по `f1_macro`.
- **Выходные документы скрипта:**
  - `folds_<exp_name>.csv` — детальные метрики на слепом тесте по каждому из 5 фолдов для каждой конфигурации.
  - `SUMMARY.csv` — сводная таблица результатов всех 9 моделей в формате `mean ± std (CI: ±ci95)` по распределению Стьюдента и суммарные матрицы ошибок (`CM_Sum_All_Folds`).

## 6. Установка и запуск

### Требования
1. Python 3.9+ и GPU с поддержкой CUDA (для дообучения `RuBERT` в режиме `FP16`).
2. Локальный сервер [Ollama](https://ollama.com/) с моделью `llama3` (для шагов генерации 00–02):
   ```bash
   ollama pull llama3
   ```

### Быстрый старт
1. Клонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/Scripts/activate  # Для Windows (Git Bash)
   # source .venv/bin/activate    # Для Linux/macOS
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Для запуска полного цикла генерации и подготовки выборок:
   ```bash
   python run_pipeline.py
   ```
4. Для запуска 5-фолдовой кросс-валидации всех 9 конфигураций модели RuBERT и генерации `SUMMARY.csv`:
   ```bash
   python src/data_generation/07_train_rubert_cv.py
   ```
